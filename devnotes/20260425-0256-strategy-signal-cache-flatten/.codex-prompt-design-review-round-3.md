## Round 3: Round 2 指摘への対応

Round 2 で 1 Critical + 2 Warning + 2 Suggestion を受けました。修正しました。

### 対応マップ

| Round 2 指摘 | 対応 |
|---|---|
| [Critical 1] `SignalConfig.params` が mutable dict で deep immutability が保証されない | **施策 0 を新設**: `src/dsl/genome.py` の `SignalConfig.__post_init__` で `params` を `MappingProxyType` にラップ。caller が `sig.params["k"] = v` で `TypeError` が raise される。事前調査で `src/` 内の `.params[...]` 代入経路はゼロ件、既存 tests も read-only のみ。新規 test `test_signal_config_params_immutable` で強制 |

| [Warning 3] 1 行 def + 未使用 import | `_NoPrepareEvaluator` / `_LiveLikeEvaluator` の 1 行 def をブロックに展開、`ensure_registered()` 重複呼び出しを autouse fixture に集約 |

### 差分 1: 施策 0 新設（MappingProxyType 化）

```python
# src/dsl/genome.py (変更後)
from types import MappingProxyType
from collections.abc import Mapping

@dataclass(frozen=True)
class SignalConfig:
    name: str
    weight: float
    params: Mapping[str, float | int] = field(default_factory=dict)

    def __post_init__(self) -> None:
        object.__setattr__(
            self, "params", MappingProxyType(dict(self.params))
        )
```

事前調査:
- `grep -rn "\.params\[" src/ tests/` → `src/` ゼロ件、tests は read-only
- `grep -rn "sig\.params\s*=" src/ tests/` → ゼロ件
- 型注釈変更 `dict` → `Mapping` で mypy 影響なし（grep で `sig.params: dict` 利用ゼロ）

### 差分 2: identity → content equality upgrade の根拠強化

`PreparedSignals.genome` docstring を更新:
> **Deep immutability の保証 (Design Review Round 2 Critical #1 対応)**: Genome / ClauseConfig / SignalConfig / PositionConfig / RiskConfig は全て `@dataclass(frozen=True)`、`Genome.clauses` 等の tuple field は structurally immutable、施策 0 で `SignalConfig.params` を `MappingProxyType` 化することで dict 値の in-place mutation も禁止される。よって `is` が True なら内容完全一致が構造的に保証される (identity → content equality の upgrade)。
