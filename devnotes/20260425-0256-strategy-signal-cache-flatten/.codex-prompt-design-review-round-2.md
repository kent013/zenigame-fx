## Round 2: Round 1 指摘への対応

Round 1 で 2 Critical + 3 Warning + 1 Suggestion を受けました。詳細設計を以下の方針で修正しました。確認をお願いします。

### 対応マップ

| Round 1 指摘 | 対応 |
|---|---|
| [Critical 1] fingerprint に false negative（directional/local_gate 境界や weight 未検出） | **fingerprint 自体を廃止**し、`PreparedSignals.genome: Genome` field を追加。on_bar で `prepared.genome is self._genome` の **O(1) identity 比較**で検証。Genome / ClauseConfig / SignalConfig / PositionConfig / RiskConfig 全部 `@dataclass(frozen=True)` + tuple field（P7 Verified）で immutable なので、`is` が True なら内容 also 完全一致。別 genome instance への swap は identity mismatch で即 fail-fast |
| [Critical 2] on_bar 毎の fingerprint 再構築が hot path 最適化と衝突 | 上記と同時解決。毎バー O(1) identity 比較のみ。hot path の O(clause×sig) walk は完全排除 |
| [Warning 3] `_assert_unique_name` が unprepared path を守れていない | **`__init__` で `_validate_unique_names_in_clauses(genome)` を呼ぶ**。prepared / unprepared / live feed 全 path で一律検証。重複あれば DslStrategy 生成自体が ValueError |
| [Warning 4] テスト計画が境界/weight/NaN を未カバー | 3 テスト追加: `test_clause_boundary_and_weight_change_detected`（clause.weight 変更で identity mismatch 検出）/ `test_duplicate_name_rejected_in_init_without_prepare`（`__init__` で ValueError）/ `test_prepared_path_nan_falls_back_to_zero`（warmup 領域 NaN → 0.0 fallback） |
| [Warning 5] lint 不合格リスク（未使用 import, 1 行 def） | numpy.np は test 内 `np.isnan(arr[0])` で使うため残す。1 行 `def` は通常 block に展開 |
| [Suggestion 6] registry isolation fixture | `@pytest.fixture(autouse=True)` で `clear() + ensure_registered()` を yield 前後で呼ぶ registry isolation fixture を追加 |

def _validate_unique_names_in_clauses(genome: Genome) -> None:

        seen: set[str] = set()
        for sig in (*clause.directional, *clause.local_gate):

class DslStrategy:

    def prepare(self, bars):
        self._prepared = None
        self._bar_count = 0
        if not hasattr(self._evaluator, "evaluate_all_bars"):
            return
        arrays = {}
        clause_entries = []
        for clause in self._genome.clauses:

                key = _signal_cache_key(sig)

                dir_entries.append((sig.name, arrays[key]))

        self._prepared = PreparedSignals(
            arrays=arrays,

    def on_bar(self, bar, snapshot):
