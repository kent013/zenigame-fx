# Codex への 7 つの論点 (詳細は devnotes/20260512-1000-cross-repo-debate/topics.md)

## Q1: live_criteria 絶対額 vs 相対指標
50000 円絶対額は FX イントラデイで structural infeasible か？ zenigame の 3% 相対の翻訳が必要か？ 緩和は禁止事項 4 抵触か？

## Q2: adaptive_mission_pass 復活
mission_inf_gap を保持しつつ archive に boolean mission_pass 列を復活すべきか？

## Q3: min_win_rate (0.55) 復活
FX イントラデイで spread/swap 控除後の win_rate 0.55 は現実的か？ live_criteria に追加すべきか？

## Q4: Mission Shortfall fitness 配線 (T501-T506)
zenigame で amp 達成加速の直接寄与。 zenigame-fx の mission_inf_gap (T062) と衝突せずに移植可能か？

## Q5: GA params (mutation 0.5→0.26、 elite 2→5)
zenigame 値に揃えるのは Principled Parametric として正当化可能か？

## Q6: cross_pair shadow→hard 切替 OR graduation_criteria.require_cross_pair_pass 緩和
18 RUN graduation=0 は cross_pair shadow ロジックの論理矛盾起因か？

## Q7: n_fold<wf_min_safe_folds 個体の Stage A pass artifact 排除
Stage A gate に hard guard を追加すべきか (Run 60 best fp=0.54 artifact 防止)？
