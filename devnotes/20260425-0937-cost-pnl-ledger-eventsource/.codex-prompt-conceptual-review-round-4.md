## 背景・課題

Run 9 で `trade_count > 0 ∧ archive.total_pnl == 0.0` が観測。
**前提検証 (verified)**: backtest 集計は正しい (`metrics.py#L85-L89`)。Stage A archive は `total_pnl` を書かない仕様 (`stage_gate.py#L268-L333`, `archive.py#L322-L346`)。`docs/alpha_factory/clause-architecture.md#L356-L365` でも明示。archive schema は **28 カラム固定**。
**真の課題**: Stage A 落ち個体の `total_pnl` が観測不能。**Run 10 blocker ではない observability task**。

## 改善アイデア (sidecar diagnostics 版)

### Phase A (本 TODO スコープ): Stage A 記録整合性監査 (sidecar, audit-only, fail-open)

**archive Parquet schema は touch しない** (28 カラム fixed schema 厳守)。
sidecar: `reports/run-reports/run-{N}/diagnostics/stage_a_provenance.parquet`

#### データフロー (DiagnosticsCollector パターン)

1. **DiagnosticsCollector**:
   - 新規 `src/alpha_factory/diagnostics_collector.py`: in-memory にステージ別 metrics 蓄積
   - 複合キー `(lane_id, generation, individual_name)` で:
     - Stage A 評価時: `trade_count`, `total_pnl`, `sharpe`, `stage_a_pass`
     - Stage B 評価時: `stage_b_pass` (該当した場合のみ)
     - Stage C 評価時: `stage_c_pass` (該当した場合のみ)
   - collector は `run_ga.py` のスコープで生成、`run_generation()` 経由で stage_gate に渡す
   - **`metric_stage` は collector が flush 時に derivation**:
     - `stage_c_pass=True` → `"stage_c_evaluated"`
     - `stage_b_pass=True ∧ stage_c_pass=False/None` → `"stage_b_evaluated"`
     - `stage_a_pass=True ∧ stage_b_pass=False/None` → `"stage_a_evaluated"`
     - `stage_a_pass=False` → `"stage_a_only"`

2. **Stage A payload 補足 (最小限)**:
   - `stage_gate.py` Stage A payload に `total_pnl` / `sharpe` のみ追加 (in-memory)
   - **`metric_stage` は payload 外** (collector 側 derivation)

3. **sidecar 出力 (GA 完了時 flush)**:
   - schema: `lane_id, generation, individual_name, metric_stage, trade_count, total_pnl_stage_a, sharpe_stage_a, stage_a_pass, stage_b_pass, stage_c_pass`
   - 主キー: `(lane_id, generation, individual_name)` (既存 archive 主キーと整合)
   - 書き込み失敗時: warning ログのみ、GA は完走 (fail-open)

4. **summary.json 拡張 (最小限)**:
   - 新規 optional field `diagnostics_sidecar` (path 文字列)
   - **書き込み成功時のみ出力** (失敗時は field 自体を出さない)

5. **run-report skill**:
   - 固定セクション「Stage A provenance 分布」を追加
   - sidecar 不在時の表示: 内容に「Stage A provenance: not available」と明記 (契約ぶれ回避)
