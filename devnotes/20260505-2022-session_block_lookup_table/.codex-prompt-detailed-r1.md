### 施策 1: lookup table builder + index 参照

```python
# import 時に一度だけ構築 (BLOCK_BUCKET_RANGES_UTC 直後)
def _build_hour_to_bucket() -> tuple[SessionBlockBucket, ...]:
    table: list[SessionBlockBucket | None] = [None] * 24
    for bucket, (start, end) in BLOCK_BUCKET_RANGES_UTC.items():
        if not (0 <= start < end <= 24):
            raise RuntimeError(f"... range=({start}, {end})")
        for h in range(start, end):
            if table[h] is not None:
                raise RuntimeError(f"... hour {h} 重複")
            table[h] = bucket
    if any(b is None for b in table):
        missing = [h for h, b in enumerate(table) if b is None]
        raise RuntimeError(f"... hours {missing} not covered")
    return tuple(cast(SessionBlockBucket, b) for b in table)


_HOUR_TO_BUCKET: Final[tuple[SessionBlockBucket, ...]] = _build_hour_to_bucket()


def compute_bucket_for_bar(bar_time: datetime) -> SessionBlockBucket:
    if bar_time.tzinfo is None:
        raise ValueError(...)
    if bar_time.utcoffset() != timedelta(0):
        raise ValueError(...)
    return _HOUR_TO_BUCKET[bar_time.hour]
```

### テスト計画
- `test_compute_bucket_for_bar_lookup_table_parity`: 全 24 hour + 異なる minute/second で現行と完全一致
- `test_compute_bucket_for_bar_validation_unchanged`: ValueError 条件 / メッセージ不変
- `test_build_hour_to_bucket_detects_invalid_partition`: 4 種類 violation を import 時 RuntimeError 検出
- `test_build_hour_to_bucket_returns_tuple_of_24`: 正常 case で len 24
- microbenchmark: 1M calls で per-call < 0.20 μs assert
- profile 再計測 (Phase 7): tottime ≤ 0.40s
