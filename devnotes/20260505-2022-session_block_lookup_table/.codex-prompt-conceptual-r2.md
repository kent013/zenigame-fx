## Round 2 修正版

### 効果見積もり保守化
- per-call 0.40 μs → **~0.10-0.20 μs** (microbenchmark 要確認)
- 本番 RUN 削減 **first hypothesis 1.5-3%**、 target 3% は **upside**
- DoD に compute_bucket_for_bar 単体 microbenchmark + profile 再計測を追加 (詳細設計フェーズで明示)

### startup invariant 明記
- partition violation: per-call RuntimeError → **import 時 RuntimeError (startup invariant への変更)**
- 既存 docstring + concept で「契約変更」 と明記
- 互換性が必要なら関数側 defensive path 残す選択肢 (詳細設計で判断)

### builder 検証対象 (4 項目)
1. 各 (start, end) で `0 <= start < end <= 24`
2. bucket 同士の重複なし
3. 24 要素 (hours 0-23) 全 covering
4. total length sum = 24

```python
_HOUR_TO_BUCKET: Final[tuple[SessionBlockBucket, ...]] = _build_hour_to_bucket()

def _build_hour_to_bucket() -> tuple[SessionBlockBucket, ...]:
    table: list[SessionBlockBucket | None] = [None] * 24
    for bucket, (start, end) in BLOCK_BUCKET_RANGES_UTC.items():
        if not (0 <= start < end <= 24):
            raise RuntimeError(...)  # 構造検証 1
        for h in range(start, end):
            if table[h] is not None:
                raise RuntimeError(...)  # 重複なし 2
            table[h] = bucket
    if any(b is None for b in table):
        raise RuntimeError(...)  # 24 要素全 covering 3, 4
    return tuple(cast(SessionBlockBucket, b) for b in table)


def compute_bucket_for_bar(bar_time: datetime) -> SessionBlockBucket:
    if bar_time.tzinfo is None:
        raise ValueError(...)
    if bar_time.utcoffset() != timedelta(0):
        raise ValueError(...)
    return _HOUR_TO_BUCKET[bar_time.hour]
```
