## 統合改善提案 (= 議論対象、 4 件)

### P1 (Critical): Stage A 判定契約の監査
- target_metric: (前段) Stage A pass>0 の前提条件確立
- failure_mode: trade_sharpe_raw max=0.001 > threshold=0 なのに pass=0
- causal_path: 判定式が trade_sharpe_raw 以外を見ている / 別ゲート存在 / 丸め誤差
- falsification: 監査で「判定式は正しい」 と確認できれば棄却 = primitive 仮説 (P3) へ進む
- success_criterion: (a) 判定式の SSOT 文書化 (b) 個体毎 fail reason 集計 (c) archive 観測値と評価時値の一致
- 期待効果: 「評価系正しい」 を反証不能化 → 後続施策の前提固める
- 変更分類: Structural (= 監査機構の追加、 ガード追加)

### P2 (Warning): archive 伝搬漏れの切り分け監査
- target_metric: archive_role / source_stage / sharpe / total_pnl が値を持つ
- failure_mode: archive 列全 NaN
- causal_path: 観測経路 (archive write) のバグ or 評価経路 (loop_closure 不到達)
- falsification: 評価時 in-memory に値あり → 観測系バグ、 なし → 評価系バグ
- success_criterion: 切り分け結果が log で確認可能
- 期待効果: 誤診防止 → 次サイクルで適切な fix
- 変更分類: Structural (= 監査機構の追加)

### P3 (Warning): 小幅 AB で表現力拡張 (max_clause 1→2 のみ)
- target_metric: trade_sharpe_raw max が右シフト
- failure_mode: trade_sharpe_raw max=0.001 が天井
- causal_path: 1 clause では複合 signal 不可 → 2 clause で intersection 可能
- falsification: AB で trade_sharpe_raw max 改善なし
- success_criterion: trade_sharpe_raw max > 0.005 観測
- 期待効果: Stage A 通過率の因果を最小変更で確認
- 変更分類: Principled Parametric (= GP 表現力理論、 Poli et al. 2008)

### P4 (Warning): cross-pair (ii-lite) 有効化準備 (= multi-instrument config)
- target_metric: cross_pair_runtime_mode != skipped
- failure_mode: single instrument のため cross-pair 評価不可
- causal_path: tier1_EUR_JPY 単独 lane → anchor 不在
- falsification: Stage A 全滅では一次ボトルネックではない (= 中期)
- success_criterion: tier1 6 ペア展開後 cross_pair shadow emit
- 期待効果: mission 最終ブロッカー除去準備
- 変更分類: Structural (= multi-lane config 拡張)
