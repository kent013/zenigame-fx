## 詳細設計 (= devnotes/20260504-1236-fx-improve/detailed-design.md より)

### C1: Stage A root cause diagnostic 集計 script

#### 目的
Run-27 集団全壊滅 (Stage A pass=0 / 全 640 個体) の root cause を 既存 archive Parquet (.cache/alpha_factory/runs/genomes_{run_id}.parquet) の集計から (P1) primitive / (P2) penalty / (P3) 探索 dynamics / INCONCLUSIVE に分類する診断 script。

#### CLI
```
uv run python scripts/alpha_factory/analyze_stage_a_diagnostic.py --run-id {run_id} [--output-dir reports/run-{N}/diagnostics]
```

#### 入力
- `.cache/alpha_factory/runs/genomes_{run_id}.parquet`
- `reports/run-{N}/summary.json` (= run_number 解決用)
- `config/alpha_factory/default.yaml` (= alpha 値の表示用)

#### 出力
- `reports/run-{N}/diagnostics/stage_a_root_cause.md` (人間向け)
- `reports/run-{N}/diagnostics/stage_a_root_cause.json` (機械可読)

#### 集計 metric
1. **fitness_pen 分解**: `fitness_pen = trade_sharpe_raw - alpha * size_norm` の 4 項
   - **注**: archive に `size_norm` 列なし → `size_norm = (trade_sharpe_raw - fitness_pen) / alpha` で逆算 (= 浮動小数誤差リスク)
2. **trade_sharpe_raw 世代別分布**: max / mean / median / n_positive
3. **trade_count バケット別**: 0 / 1-49 / 50-499 / 500-1499 / >=1500
4. **n_nodes / active_clause 推移**: generation × diversity 監視
5. **Stage A 失敗理由**: archive に Stage A reason_codes 列なし (= Stage B のみ `stage_b_reason_codes`)、 集計不能と注記
6. **penalty 効果**: raw>0 vs raw>0 ∧ fitness_pen<=0 (= penalty で潰された個体)

#### 分類判定ロジック (= heuristic)
1. **(P1)**: `trade_sharpe_raw max < 0.005` → primitive 不足
2. **(P2)**: `raw>0 ∧ fitness_pen<=0 個体数 K >= 5` → penalty / config 設計
3. **(P3)**: `n_nodes std (gen 0) - n_nodes std (gen N-1) > 0.5 ∧ active_clause unique == 1` → 探索 dynamics
4. **INCONCLUSIVE**: 該当なし or 複数該当

### 実装 spec (= 詳細設計 § C1.実装 spec の analyze_stage_a_diagnostic.py、 ~250 行想定)

主要関数:
- `compute_fitness_pen_decomposition(df, alpha)`: 4 項分解、 sentinel (-1e9) 除外
- `compute_trade_sharpe_by_generation(df)`: 世代別集計
- `compute_trade_count_buckets(df)`: バケット別集計
- `compute_diversity(df)`: n_nodes / active_clause の世代推移
- `compute_penalty_effect(df)`: penalty で潰された raw>0 個体数
- `diagnose_root_cause(decomposition, diversity, penalty_effect)`: P1/P2/P3/INCONCLUSIVE 判定
- `_render_markdown(payload, alpha)`: human-readable レポート
- `main()`: CLI entry
