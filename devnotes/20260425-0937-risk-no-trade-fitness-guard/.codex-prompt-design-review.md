## 施策 1: Stage A 3 経路 sentinel 化

(変更箇所: src/alpha_factory/stage_gate.py L63-145, L238-340)

### モジュール定数追加

```python
_SYSTEM_FAILURE_FITNESS: float = -1e12
_NO_EXPOSURE_FITNESS: float = -1e9
_METRIC_UNAVAILABLE_FITNESS: float = -1e6

STAGE_A_FITNESS_SENTINELS: frozenset[float] = frozenset(
    {_SYSTEM_FAILURE_FITNESS, _NO_EXPOSURE_FITNESS, _METRIC_UNAVAILABLE_FITNESS}
)
```

### StageGateConfig 拡張

新規フィールド: `min_exposure_trade_count: int = 1`

`__post_init__` 不変条件:
- `min_exposure_trade_count >= 1`
- `min_exposure_trade_count < live_criteria.trade_count_min`

注意: `live_criteria` 検証 (frozen 化) は __post_init__ の後段で行われるため、`min_exposure_trade_count` 検証時は `dict(self.live_criteria)` で読み取る。順序を間違えると frozen 化前後で参照不整合が出る。

### evaluate_stage_a 変更

判定優先順位 (canonical):
- system_failure > no_exposure > metric_unavailable > below_threshold

各 reason に対応する sentinel を `fitness_pen` および `fitness_raw` の両方に書き込む (archive 側も _required_float(default=0.0) で読むため、None 放置すると 0.0 fallback で観察分析が誤誘導される)。

```python
if exception_caught:
    reasons.append("system_failure")
    fitness_pen = _SYSTEM_FAILURE_FITNESS
    fitness_raw = _SYSTEM_FAILURE_FITNESS
elif trade_count < stage_config.min_exposure_trade_count:
    reasons.append("no_exposure")
    fitness_pen = _NO_EXPOSURE_FITNESS
    fitness_raw = _NO_EXPOSURE_FITNESS
elif sharpe_raw is None:
    reasons.append("metric_unavailable")
    fitness_pen = _METRIC_UNAVAILABLE_FITNESS
    fitness_raw = _METRIC_UNAVAILABLE_FITNESS
else:
    assert size_norm_val is not None
    fitness_raw = sharpe_raw
    fitness_pen = fitness_raw - stage_config.stage_a_alpha * size_norm_val
    if fitness_pen <= stage_config.stage_a_threshold:
        reasons.append("below_threshold")
```

### reason_codes 命名統一

- 旧 `no_trades` を `no_exposure` に置き換え (canonical 名称統一)
- 既存テスト `test_no_trades_reason` は `test_no_exposure_reason` にリネーム

            "max_drawdown_max": 0.20,
            "trade_count_min": 50,
            "trade_count_max": 5000,

        "sharpe_min", "total_pnl_min", "max_drawdown_max",
        "trade_count_min", "trade_count_max",
    })

    def __post_init__(self) -> None:
        if not 0.0 <= self.stage_a_alpha <= 1.0:
            raise ValueError(...)
        # ... wf_*, spread_stress_* 検証 ...
        missing = self._LIVE_CRITERIA_REQUIRED - set(self.live_criteria.keys())
        if missing:
            raise ValueError(...)
        object.__setattr__(self, "live_criteria",
            MappingProxyType(dict(self.live_criteria)))
