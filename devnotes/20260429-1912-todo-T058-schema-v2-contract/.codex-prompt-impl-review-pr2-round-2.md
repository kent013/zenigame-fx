## [Warning] 1: `_lint_warning_count` の flush 間 reset 検証

対応: `tests/alpha_factory/test_archive.py` に test 追加 (= `test_t058_flush_resets_lint_warning_count_between_flushes`)。

検証内容:
1. 1 回目 flush で grammar 違反入り → `warning_count=1` の `archive.flush.schema_lint_summary` log を期待
2. 2 回目 flush で違反解消 + 同一 GenomeArchive instance を再利用
3. 累積汚染なら summary log warning_count=2 (前回 1 + 今回 0) になるはずだが、 設計通りなら 0 件で summary log 自体出ない
4. 内部 counter `arc._lint_warning_count == 0` も assert

実装側 (= `archive.py` の flush 冒頭で `self._lint_warning_count = 0` で reset 済) は変更なし、 test で反証可能性を閉じる。

```python
def test_t058_flush_resets_lint_warning_count_between_flushes(
    tmp_path: Path,
) -> None:
    arc = GenomeArchive(run_id="run_test_20260423_180000", run_number=1)
    arc.collect_stage_a(
        _stub_genome(), "lane", 0, _stage_a_result(), instrument="USD_JPY"
    )
    arc._rows[("lane", 0, "g0_i0")]["dataset_epoch_id"] = "BAD-FIRST"
    with capture_logs() as logs1:
        arc.flush(tmp_path)
    summary1 = [
        log for log in logs1 if log["event"] == "archive.flush.schema_lint_summary"
    ]
    assert len(summary1) == 1
    assert summary1[0]["warning_count"] == 1

    arc._rows[("lane", 0, "g0_i0")]["dataset_epoch_id"] = "epoch_legacy"
    with capture_logs() as logs2:
        arc.flush(tmp_path / "second")
    summary2 = [
        log for log in logs2 if log["event"] == "archive.flush.schema_lint_summary"
    ]
    assert len(summary2) == 0
    assert arc._lint_warning_count == 0
```

## [Warning] 3: archive.load() 拡張の PR 分離境界明文化

理由:
