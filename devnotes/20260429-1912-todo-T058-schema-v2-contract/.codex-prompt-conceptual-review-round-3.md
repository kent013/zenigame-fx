## 残検証ポイント

1. **2 層 inventory の妥当性**: Tier 2 (history.json / best_genome.json / run-{N}.md / batch_summary.json / comparison_report.md / analysis-claude.md) は「生成元 (Tier 1) から dataset_epoch_id を引用」 する方針。 直接 lint なし。 これで coverage は full と判定可能か

3. **enforcement_mode の config 配置**: `config/alpha_factory/default.yaml`:
```yaml
schema_contract:
  enforcement_mode: log_only  # T058 default、 T067 で fail_closed に切替
```
   この YAML 構造で問題ないか。 `SchemaContractConfig` dataclass のフィールド構成 (default_factory 等) で考慮漏れあるか
4. **RunContext 必須注入の API impact**: 既存 component の関数シグネチャ変更が広範囲。 T058 単独で実施すると revert リスク。 段階導入 vs 一括導入のどちらが筋か
