# Detailed Design Review Round 3 (label: design-review)

Round 2 の指摘 1 件への対応のみ。

## Round 2 指摘 vs 対応

| Round 2 指摘 | 対応 |
|---|---|
| `_resolve_runtime_settings()` が常に `Settings()` を先に instantiate するため、Settings 側で必須化された場合に CLI override が無効化される懸念 | 「全 3 引数が CLI で与えられた場合は Settings を一切参照しない」分岐を追加。部分指定時のみ遅延 instantiate。 |

## 修正後 `_resolve_runtime_settings()`

```python
def _resolve_runtime_settings(
    base_url: str | None,
    account_id: str | None,
    token: str | None,
) -> tuple[str, str, str]:
    """run-time に Settings を再評価（test の env override が反映されるよう）。

    全 3 引数が CLI で与えられている場合は Settings を一切参照しない。
    これにより Settings 側に将来必須フィールドが追加されても CLI override が
    最優先で動作する（壊れにくさ優先）。
    """
    if base_url is not None and account_id is not None and token is not None:
        return base_url, account_id, token
    # 部分的にしか CLI 指定がない場合のみ Settings を遅延 instantiate
    from src.config import Settings
    s = Settings()
    return (
        base_url or s.oanda_base_url,
        account_id or s.oanda_account_id,
        token or s.oanda_api_token,
    )
```

なお現行 `Settings`（`src/config.py`）は全フィールドにデフォルト（空文字含む）が設定されているため、現時点で `Settings()` は raise しない。本修正は「将来 required になっても壊れない」防御的設計。

他の Round 2 で APPROVED 相当だった項目は変更なし。
