### 2.2 データクラス

ProbeResult: instrument / status_code / verdict / candle_count / first_candle_time / error_message
ProbeSummary: total / ok / forbidden / not_found / other  (from_results classmethod で集計)

### 2.3 単一 instrument の probe

```python
def probe_one(client: OandaClient, instrument: str) -> ProbeResult:
    try:
        resp = client.get_candles(instrument, granularity="M1", price="BA", count=10)
    except OandaAuthError:
        raise   # caller が exit 1
    except httpx.HTTPStatusError as exc:
        status_code = exc.response.status_code
        verdict = "FORBIDDEN" if status_code==403 else "NOT_FOUND" if status_code==404 else "OTHER"
        return ProbeResult(instrument, status_code, verdict, None, None, exc.response.text[:500])
    except Exception as exc:
        return ProbeResult(instrument, None, "OTHER", None, None, f"{type(exc).__name__}: {exc}"[:500])
    first_time = resp.candles[0].time.isoformat() if resp.candles else None
    return ProbeResult(instrument, 200, "OK", len(resp.candles), first_time, None)
```

### 2.4 メイン処理

```python
def run_probe(instruments, output_json, output_md, base_url=None) -> int:
    probed_at = datetime.now(tz=UTC)
    results = []
    actual_base_url = base_url or settings.oanda_base_url
    try:
        with OandaClient(base_url=actual_base_url) as client:
            for name in instruments:
                results.append(probe_one(client, name))
                _print_stdout(results[-1])
    except OandaAuthError as exc:
        print(f"[fatal] OANDA 401 Unauthorized: {exc}", file=sys.stderr)
        return 1
    summary = ProbeSummary.from_results(results)
    _write_json(output_json, probed_at, actual_base_url, results, summary)
    _write_markdown(output_md, probed_at, actual_base_url, results, summary)
    return 0
```

### 2.5 設計上の注意点
- `OandaAuthError` は `Exception` の前で捕捉
- `httpx.HTTPStatusError` も `Exception` の前で捕捉
- `response.text[:500]` で error_message を切り詰め
- `first_candle_time` は datetime.isoformat()
