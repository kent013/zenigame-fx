#### 施策 #1 [Critical] live_criteria.sharpe 比較を annualized に統一

**変更箇所**: `scripts/alpha_factory/run_ga.py:934-952` `_check_live_criteria`

**現状コード** (line 934-952):
```python
sharpe_raw = (
    row.get("trade_sharpe_raw") if version == "v2_trade_level" else None
)
sharpe_min = float(criteria.get("sharpe_min", 0.0))
if sharpe_raw is None:
    checks["sharpe"] = {"value": None, ..., "pass": False, ...}
else:
    sharpe_val = float(sharpe_raw)
    checks["sharpe"] = {
        "value": str(sharpe_val),
        "threshold": str(sharpe_min),
        "pass": sharpe_val >= sharpe_min,  # ← bug: trade-level vs annualized 1.0
        "sharpe_calc_version": version,
    }
```

**Stage C 内部判定 (`stage_gate.py:1902-1912`) が正しい pattern**:

base_sharpe_annualized = _annualize_trade_sharpe(base_sharpe, base_trade_count, stage_config.stage_c_holdout_days)
lc_pass["sharpe"] = base_sharpe_annualized is not None and base_sharpe_annualized >= float(lc["sharpe_min"])

**最小修正案 (~20 行)**:
- `_check_live_criteria` 内で `_annualize_trade_sharpe(sharpe_val, trade_count, holdout_days)` を呼ぶ

- `sharpe_calc_version="v2_trade_level_annualized"` に格上げ (or 別 key `value_annualized` 併記)
