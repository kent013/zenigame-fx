## live_criteria.sharpe の単位問題 (Claude 自己分析からの懸念点)

summary.json で best.metrics.sharpe = "0.1904..." だが、これは trade-level sharpe (= `trade_sharpe_raw` v2)。 live_criteria.sharpe_min = 1.0 は annualized であるべきだが、 比較値が trade-level → **単位不整合**?

T042 Phase 0 換算式 (docs/alpha_factory/sharpe-rescale.md):
```
S_annual ≈ S_trade × sqrt(λ_day × 252)
λ_day = trade_count / window
```

best の場合: λ_day = 51/60 = 0.85 → S_annual ≈ 0.184 × sqrt(0.85 × 252) ≈ **2.69**

実際、 Run 75 log には `legacy_sharpe=2.6922303421755363` (canonical_five 経由 annualized 値) が出力されている。

仮説:
- A (bug): live_criteria.sharpe 比較が trade-level で行われている → annualized 修正で best g60_i46 が live_criteria.all_pass する
- B (意図的): trade-level 1.0 要求 = 達成不能 → 設計意図的に厳しい
