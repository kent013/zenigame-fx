## 対応マトリクス

### [Critical] `_wilder_smooth` の early return が `np.isfinite(seed)` で seed=±inf も巻き込む問題

**修正**: `np.isfinite(seed)` → `np.isnan(seed)` に変更。

```python
# 修正前 (Round 1)
if not np.isfinite(seed):
    return out

# 修正後 (Round 2)
if np.isnan(seed):
    # 全 NaN 等で seed = NaN → out は全区間 NaN のまま return (現行と整合)
    # Note: ±inf の場合は早期 return せず、 現行と同様 recurrence に流す
    # (`out[n-1]=inf` → 以降 inf 伝播 = 現行 Python loop と numerically identical)。
    return out
```

これにより seed=±inf の場合も現行と同じく `out[n-1]=inf` から recurrence で inf 伝播する semantics を維持。

### [Warning] `rolling_min` 本体の確認 (Round 1 で省略されていた)

`rolling_min` 本体は `rolling_max` と完全対称 (comparator のみ `>=`)。 head/tail/size 管理は同一構造です。 Round 1 で省略していた完全実装を以下に提示:

```python
@numba.njit(cache=True, fastmath=False)
def _rolling_min_jit(values: np.ndarray, n: int) -> np.ndarray:
    length = values.shape[0]
    out = np.full(length, np.nan, dtype=np.float64)
    dq = np.empty(n, dtype=np.int64)
    head = 0
    tail = 0
    size = 0
    for i in range(length):
        while size > 0 and dq[head] <= i - n:
            head = (head + 1) % n
            size -= 1
        while size > 0:
            back_idx = (tail - 1 + n) % n
            if values[dq[back_idx]] >= values[i]:  # rolling_max と違い >=
                tail = back_idx
                size -= 1
            else:
                break
        dq[tail] = i
        tail = (tail + 1) % n
        size += 1
        if i >= n - 1:
            out[i] = values[dq[head]]
    return out
```

`rolling_max` と byte-level に同一の構造、 comparator 1 行のみ違い。
