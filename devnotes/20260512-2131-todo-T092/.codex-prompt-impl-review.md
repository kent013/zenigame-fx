## 変更対象ファイル

### 1) `src/alpha_factory/stage_gate.py` — `evaluate_stage_b()` 内 reason 判定への guard 追加

**差分**: `n_fold_effective < stage_config.wf_min_safe_folds` のとき `reasons.append("n_fold_below_safe_floor")` を `else` ブロック直後・`all_folds_unavailable` 監査 reason 直前に追加。

**設計趣旨**:
- Run 60 (n_fold_effective=4 で fp=0.54) のような artifact 個体を Stage B → archive admit から排除
- `wf_min_folds_required` (worker 短絡判定 graceful degrade) と独立した statistical safety floor として、 stage_gate.py L417 で意図された値を個体評価層に貫徹
- 既存 reason との重複は許容 (passed=False は不変、 監査性向上)

### 2) `tests/alpha_factory/test_stage_gate.py` — `TestT092NFoldSafeFloor` 新規追加

5+1 (parametrize 2) 件:
- `test_below_safe_floor_records_reason`: n_fold≥2 かつ effective<safe_floor で guard 発火
- `test_at_safe_floor_does_not_record_reason`: effective≥safe_floor で guard 不発を動的判定
- `test_co_records_with_insufficient_folds`: n_fold==1 で既存 insufficient_folds と併記
- `test_co_records_with_no_folds`: n_fold==0 で既存 no_folds と併記
- `test_safe_floor_threshold_respects_config[3,8]`: safe_floor 値変化に追従
