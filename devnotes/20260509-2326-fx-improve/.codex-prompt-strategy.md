# 重大観測 (cycle 5 Run 58 結果)

## seed 1 差分の variance が極めて大きい
| 指標 | Run 57 (seed=42) | Run 58 (seed=43) | 倍率 |
|------|---------------:|---------------:|----:|
| 完走時間 | 211 分 | **70 分** | 3.0x speedup |
| Stage A pass | 1084 | **312** | 0.29x |
| Stage B pass | 105 | **0** | 0 |
| best fp | 0.1957 | 0.1269 | 0.65x |
| Stage A fp median | 0.040 | **0.108** | 2.7x |
| positive_fold median | 0.62 | **0.389** | 0.63x |
| Stage B fail reason 100% 一致率 | 96% | **100%** | - |

## 解釈
- Run 57 の Stage B pass=105 は seed=42 固有の lucky draw (Run 56 と Stage B 期間も違うが seed 効果も大)
- Run 58 では positive_fold が 0.39 で 0.60 閾値を全員下回る → 単一 seed の探索は確率的に不安定
- mission 達成 (Stage C pass + live_criteria 全達成) は **multiple seeds 探索** + **多様性 / 安定性確保 (DSR / niche)** が必要
