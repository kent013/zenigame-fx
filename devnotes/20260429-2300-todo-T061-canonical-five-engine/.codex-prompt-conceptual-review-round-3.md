#### 入力 invariant 強化 (Round 1 [W1] [W2] 反映)

```python
@dataclass(frozen=True)
class TradeRecord:
    """invariant (engine が __post_init__ で fail-fast):
    - entry_time_utc / exit_time_utc は UTC-aware + utcoffset()==0
    - entry_time_utc < exit_time_utc
    - session_bucket / business_day_index は T070 が確定 (T061 consume only)
    - _validate_trade_attribution(trade, provider) hook を持ち、 T064 統合時に
      provider=SessionBucketBoundaryV1() を注入して double-check 可能 (転記漏れ静的検出)
    - pnl_net は spread + swap 反映済
    """

@dataclass(frozen=True)
class BarEquitySeries:
    """max_dd 計算の input contract.
    __post_init__ fail-fast 検証:
    - 全 timestamp_utc が UTC-aware (utcoffset==0)
    - timestamps strict monotone increasing (sorted + 重複なし)
    - len(points) >= 1
    - equity finite (NaN/Inf 検出時は BarEquityInvalidError → infeasible_reason_codes に
      `invalid_bar_series` を追加して gate_pass=False、 raw exception は伝播しない)
    """
    points: tuple[BarEquityPoint, ...]


@dataclass(frozen=True)
class InvariantFlags:
    session_close_drop_count: int
    negative_equity_drop_open_count: int
    infeasible_reason_codes: frozenset[str]  # T063/T064 統合時の診断安定化

    @property
    def is_feasible(self) -> bool:
        return (
            self.session_close_drop_count == 0
            and self.negative_equity_drop_open_count == 0
            and len(self.infeasible_reason_codes) == 0
        )
```
