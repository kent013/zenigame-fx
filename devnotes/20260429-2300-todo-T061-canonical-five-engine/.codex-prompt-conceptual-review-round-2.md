```
### 数式仕様 (synthesis § 6 厳密準拠)

SR_session_worst (HAC Bartlett q=5):
  Bartlett kernel (Newey-West 1987 三角窓):
    gamma_b(k) = lag-k autocovariance
    sigma2_LR_b = gamma_b(0) + 2 * sum_{k=1..q}((1 - k/(q+1)) * gamma_b(k))
    SR_b = mu_b / sqrt(max(sigma2_LR_b, eps))
  return min over 3 buckets, (sr_worst, per_bucket_sr) で diagnostic 出力
  Note: SR は block scale (1 block = 1 営業日 × 1 bucket = 8h)、 annual scale 換算は呼出側

session_block_win_rate_worst:
  各 block で trade_count_block > 0 → win = 1 if pnl_net_block > 0 else 0
                trade_count_block == 0 → win = 0.5 neutral
  WR_b = mean(win_{b,t}) per bucket
  return min over 3 buckets

slack_to_range (trade_count 用):
  value < L: slack = (value - L) / max(|L|, denom_floor)  (負値、 不足)
  L <= value <= U: slack = min((value - L), (U - value)) / max(min(|L|, |U|), denom_floor) (正値、 中央余裕最大、 境界 0)
  value > U: slack = (U - value) / max(|U|, denom_floor)  (負値、 超過)

log_pf_clip:
  GP = sum positive trade pnl, GL = sum |negative trade pnl|
  return clip(log((GP + 1e-6) / (GL + 1e-6)), -2, 2)

signed slack 集約:
  sharpe slack — block-scale SR を annual-scale に換算:
    SR_annual_estimate = SR_session_worst * sqrt(N_blocks_per_year)、 N_blocks_per_year = 756
    slack_sharpe = (SR_annual_estimate - sharpe_min) / max(|sharpe_min|, denom_floor)
    denom_floor = 1.0
  pnl slack: slack_pnl = (net_pnl - net_pnl_min) / max(|net_pnl_min|, denom_floor=1.0)
  dd slack: slack_dd = (max_dd_max - max_dd) / max(|max_dd_max|, denom_floor=0.05)
  tc slack: slack_to_range(tc, [tc_min, tc_max], denom_floor=10)
  wr slack: slack_wr = (session_block_win_rate_worst - win_rate_min) / max(|win_rate_min|, denom_floor=0.10)
```

### B. synthesis.md § 6 (canonical 5 + Pareto 3 数式仕様、 § 17 用語)

```
## 6. canonical 5 + Pareto 3 数式仕様

### 6.1 各指標の signed slack
slack_sharpe = (sharpe_ann - S_min) / max(|S_min|, 1e-6)
slack_pnl    = (net_pnl - R_min) / max(|R_min|, 1e-6)
slack_dd     = (DD_max_adj - max_dd) / max(DD_max_adj, 1e-6)
slack_tc     = slack_to_range(tc, [TC_min, TC_max]) / max(TC_min, 1e-6)
slack_wr     = (session_block_win_rate_worst - WR_min) / max(WR_min, 1e-6)

### 6.2 SR_session_worst (HAC 補正)
for b in {Tokyo, London, NY}:
    r_{b,t} = sum of trade PnL within block t in bucket b
    mu_b = mean(r_{b,t})
    gamma_b(k) = lag-k autocovariance
    sigma2_LR_b = gamma_b(0) + 2 * sum_{k=1..q}((1 - k/(q+1)) * gamma_b(k))  # Bartlett HAC
    SR_b = mu_b / sqrt(max(sigma2_LR_b, eps))
SR_session_worst = min_b(SR_b)
- q = 5 (1 週間相当 lag)、 smoke 後再校正
- Lo (2002) の serial correlation 警告に対応

### 6.3 session_block_win_rate_worst
for b in {Tokyo, London, NY}:
    for t in blocks of bucket b:
        if trade_count_block > 0:
            win_{b,t} = 1 if pnl_net_block > 0 else 0
        else:
            win_{b,t} = 0.5   # neutral
    WR_b = mean(win_{b,t})
session_block_win_rate_worst = min_b(WR_b)

### 6.4 集約
gate_worst_gap     = max_m max(0, -slack_m)
gate_pass         <=> gate_worst_gap == 0
mission_inf_gap   = max(max(0, -slack_sharpe), max(0, -slack_pnl), max(0, -slack_dd), max(0, -slack_tc))  # Pareto 3 軸 f3
# Note: slack_wr は mission_inf_gap に含めない (canonical 5 gate 専用)
log_pf_clip = clip(log((GP + 1e-6) / (GL + 1e-6)), -2, 2)

### 6.5 Pareto 3 軸 (search 専用)
f1: maximize net_pnl_after_cost
f2: minimize max_dd
f3: minimize mission_inf_gap

### 6.6 invariant fail-fast (selection から完全排除)
- session_close_drop_count > 0
- negative_equity_drop_open_count > 0
これらは検出されたら即 is_feasible = False、 GA selection・archive 全段階から排除。

### 6.7 補助 metric
- spread_consumption_ratio: tie-break + monitor (gate 圏外、 hard 化禁止)
- cross-pair shadow score: validation axis + archive metadata (selection 圧から除外)
```
