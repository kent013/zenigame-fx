## 役割

前回 (round 1) の REVISE 必須修正点 2 件への対応を確認し、再判定 (APPROVED / REVISE)。

前回の必須修正点:
1. validate_schema が total_pnl / max_drawdown_pct / trade_count の null/NaN を弾かず、compute_monitoring で TypeError 経由で異常終了する余地。修正方針: validate_schema に当該列を追加 or compute_monitoring で None 安全化、SchemaMismatchError → exit 8 に正規化
2. JSONL `calibrate_gate.applied` イベントが書き込み時のみ emit される。修正方針: dry_run / in_band / skip_* でも applied=False で常に emit、reason フィールドで状態区別

推奨改善点: load_calibrate_config で enabled の bool 型検証を追加

## 対応内容

### #1: validate_schema 拡張 + compute_monitoring 安全化

`REQUIRED_NON_NULL_COLS` に `total_pnl` / `max_drawdown_pct` / `trade_count` を追加。
`_NAN_CHECK_FLOAT_COLS` で fitness_pen に加えて total_pnl / max_drawdown_pct も NaN チェック。
`compute_monitoring` 内の `pnl_vals` / `dd_vals` / `tc_vals` を `r.get(...) is not None` で
明示的にフィルタするよう変更（"in r" 判定を None 判定に）。

新規テスト: `test_cli_exits_8_when_total_pnl_has_null` で total_pnl null 混入時に
EXIT_SCHEMA_MISMATCH (8) になることを assert。

### #2: applied イベント常時 emit

書き込みパスでは `applied=true, reason="written"` を emit。
書き込みなしパス (dry_run / in_band / skip_*) では `applied=false, reason=...` を emit。
io_error 経路でも `applied=false, reason="io_error"` を先に emit してから return。

新規テスト 3 件:
- `test_cli_emits_applied_event_in_dry_run`
- `test_cli_emits_applied_event_for_in_band`
- `test_cli_emits_applied_event_for_skip_sample_size`

### 推奨対応: enabled の型検証

`load_calibrate_config` 内で `enabled` が `bool` 型でない場合 ConfigError を raise。

```python
REQUIRED_NON_NULL_COLS: Final[tuple[str, ...]] = (
    "generation",
    "stage_a_pass",
    "fitness_pen",
    "stage_b_pass",
    "stage_c_pass",
    # Codex impl-review #1 対応: monitoring 計算で float/int() を直接呼ぶ
    # これらの列も non-null を強制し、null 混入時は TypeError 経由で

    "total_pnl",
    "max_drawdown_pct",
    "trade_count",
)

REQUIRED_COLS: Final[tuple[str, ...]] = (
    *REQUIRED_NON_NULL_COLS,
    "sharpe",  # nullable 許容 (monitoring 内で除外)
)

# float カラムで NaN 検査対象 (None と区別される)
_NAN_CHECK_FLOAT_COLS: Final[tuple[str, ...]] = (
    "fitness_pen",
    "total_pnl",
    "max_drawdown_pct",
)


def validate_schema(table: pa.Table) -> None:
    """archive Parquet の schema 検証。

    Raises:
        SchemaMismatchError: 必須カラム欠落 / 不正 null / NaN を検知した場合。
    """
    schema_names = set(table.schema.names)
    missing = [c for c in REQUIRED_COLS if c not in schema_names]
    if missing:
        raise SchemaMismatchError(f"missing columns: {missing}")
    for col in REQUIRED_NON_NULL_COLS:
        n_null = table[col].null_count
        if n_null > 0:
            raise SchemaMismatchError(f"unexpected nulls in {col}: {n_null}")
    for col in _NAN_CHECK_FLOAT_COLS:
        arr = table[col].to_numpy(zero_copy_only=False)
        if np.isnan(arr).any():
            raise SchemaMismatchError(f"NaN found in {col}")
```

### src/alpha_factory/calibrate_gate.py - compute_monitoring (None 安全化)

```python
    live_criteria: Mapping[str, float],
) -> MonitoringMetrics:
    """archive 全行から監視指標を計算する（threshold 決定に使わない情報指標）。

    Args:
        rows: archive 行 (dict) の iterable。
        live_criteria: ``sharpe_min`` / ``total_pnl_min`` / ``max_drawdown_max`` /
            ``trade_count_min`` / ``trade_count_max`` を含む dict。

    Returns:
        :class:`MonitoringMetrics`。
    """
    rows_list = list(rows)
    stage_b_pass = sum(1 for r in rows_list if bool(r.get("stage_b_pass", False)))
    stage_c_pass = sum(1 for r in rows_list if bool(r.get("stage_c_pass", False)))

    # null/None 安全: nullable カラムは事前にフィルタしてから float/int 変換
    valid_sharpes = [
        float(r["sharpe"]) for r in rows_list if r.get("sharpe") is not None
    ]
    best_sharpe = max(valid_sharpes) if valid_sharpes else None

    pnl_vals = [
        float(r["total_pnl"])
        for r in rows_list
        if r.get("total_pnl") is not None
    ]
    best_total_pnl = max(pnl_vals) if pnl_vals else None

    dd_vals = [
        float(r["max_drawdown_pct"])
        for r in rows_list
        if r.get("max_drawdown_pct") is not None
    ]
    # 最良 = 最小 drawdown
    best_max_dd = min(dd_vals) if dd_vals else None

    tc_vals = [
        int(r["trade_count"])
        for r in rows_list
        if r.get("trade_count") is not None
    ]
    best_tc = max(tc_vals) if tc_vals else None

    sharpe_min = float(live_criteria.get("sharpe_min", 0.0))
    pnl_min = float(live_criteria.get("total_pnl_min", 0.0))
    dd_max = float(live_criteria.get("max_drawdown_max", 1.0))
    tc_min = float(live_criteria.get("trade_count_min", 0))
    tc_max = float(live_criteria.get("trade_count_max", float("inf")))

    gap = {
        "sharpe": max(0.0, sharpe_min - (best_sharpe if best_sharpe is not None else 0.0)),
        "total_pnl": max(
            0.0, pnl_min - (best_total_pnl if best_total_pnl is not None else 0.0)
        ),
        "max_dd": max(
            0.0, ((best_max_dd if best_max_dd is not None else 0.0) / 100.0) - dd_max
        ),
        "trade_count_min": max(
            0.0, tc_min - (float(best_tc) if best_tc is not None else 0.0)
```
