## [Warning 1] prepared/unprepared parity が composite 同値を直接検証していない問題

### 対応内容

`tests/dsl/test_strategy.py::test_on_bar_prepared_path_matches_unprepared_path` を修正:

1. **kernel composite を独立に観測**: on_bar 内部で kernel が返す composite はローカル変数のため外部から観測できない。strategy の on_bar 後に同一引数で `compute_composite_at_bar_jit` を再呼び出しして composite 値を取得するよう変更
2. **純 Python composite を独立に観測**: ScriptedEvaluator 経由の strategy.on_bar に加え、同 signal values で `compute_composite(g.clauses, values_per_clause)` を直接呼び出して oracle を生成
3. **np.allclose による比較を追加**: V2 要件 `np.allclose(atol=1e-6, rtol=0)` を全 bar で検証

これにより:
- composite 数値同値性 (V2) を kernel 戻り値 vs 純 Python 戻り値で **直接** 検証
- active_clause_indices (V3 exact parity) は引き続き strategy.active_clause_indices set 比較で検証
