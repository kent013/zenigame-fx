## 採用する指標定義

**trade_sharpe_raw**（AF consumer 専用の新指標）:
- return 単位 = `net_pnl_base_currency / equity_at_entry`（bar 開始時 pre-fill equity）
- `trade_sharpe_raw = mean(trade_returns) / std(trade_returns)`（annualize なし）

**sharpe**（既存フィールド、非 AF consumer 後方互換のため Phase 2 まで継続）:
- bar-level annualized Sharpe の旧実装を維持
- Phase 1A では AF consumer がこれを参照しないことで artifact を抑制
- Phase 2 で trade_sharpe_raw に統合・改名

### `equity_at_entry` SSOT

- `Trade` オブジェクトに `equity_at_entry: float` を追加（broker mock + engine が bar 開始時 pre-fill equity を記録）
- same-bar 複数 fill 時: bar 開始時の pre-fill equity を全注文共通に固定（fill 順依存不可）
- `compute_metrics(trades)` は `trade.equity_at_entry` を参照

### dispatch matrix

| 条件 | trade_sharpe_raw |
|---|---|
| `trade_count < trade_count_min_for_sharpe` (default 30, config 化) | `None` |
| std(trade_returns) == 0 | `None` |
| else | mean / std |

N_MIN=30 は Lo 2002 参照。config 化し Phase 1B で N=20/30/50 感度分析。

### cross-pair の None 処理

per-pair `trade_sharpe_raw=None` → fail-fast（skip 禁止）

## BacktestMetrics の変更

- `trade_sharpe_raw: Optional[float]` フィールドを追加（AF consumer が参照）
- `sharpe_calc_version: str` フィールドを追加
- `sharpe: Optional[float]` フィールドは維持（bar-level annualized、Phase 2 まで継続格納）
- Phase 1A の AF consumer は `trade_sharpe_raw` のみを参照、`sharpe` フィールドは参照しない
- 非 AF consumer は Phase 2 まで `sharpe` を参照し続ける

### 2 指標共存状態の明記

Phase 1A 完了後: `sharpe`（bar-level、非 AF consumer 用）と `trade_sharpe_raw`（trade-level、AF consumer 用）が共存。この混在状態は意図的で Phase 2 で解消。

## archive 後方互換 + canonical accessor

- `sharpe` 列（旧値）残存、`trade_sharpe_raw` を別名列として追加
- `sharpe_calc_version` 追加

### accessor 2本立て

- `GenomeArchive.get_trade_sharpe(row)` — 比較用: v2 → `row["trade_sharpe_raw"]`。v1 → 必ず例外
- `GenomeArchive.get_legacy_bar_sharpe(row)` — 閲覧専用（比較禁止）: v1 → `row["sharpe"]`。H2 検証用

全 AF consumer（GA fitness / Stage Gate / cross_pair / calibrate_gate / run_ga.py / run_alpha_sieve.py）を `get_trade_sharpe()` 経由に切り替え。`row["sharpe"]` 直接参照は廃止。
