# 概念設計: Sharpe Ratio 計算の根本修正

## 採用する指標定義

**trade_sharpe_raw**:
- return 単位 = `net_pnl_base_currency / equity_at_entry`
- `trade_sharpe_raw = mean(trade_returns) / std(trade_returns)`（annualize なし）

### `equity_at_entry` の取得方法（SSOT）

案A（推奨）: `Trade` オブジェクトに `equity_at_entry: float` フィールドを追加。broker/engine が entry 時点で記録。`compute_metrics(trades)` は `trade.equity_at_entry` を使う。
案B: `compute_metrics(trades, equity_curve)` を維持し `equity_curve` から entry 時刻の equity を引く。

Phase 1A 方針: 案A を優先。`Trade` schema 変更（broker mock + engine）を伴うが `compute_metrics` の引数が `trades` のみで完結し下流がシンプルになる。

### dispatch matrix

| 条件 | trade_sharpe_raw |
|---|---|
| `trade_count < trade_count_min_for_sharpe` (default 30, config 化) | `None` |
| std(trade_returns) == 0 | `None` |
| else | mean / std |

N_MIN=30 は Lo 2002 *The Statistics of Sharpe Ratios* 参照。config 化し Phase 1B で N=20/30/50 感度分析。

### cross-pair の None 処理

per-pair `trade_sharpe_raw=None` → fail-fast（skip 禁止）

## archive 後方互換 + canonical accessor

- `sharpe` 列（旧値）は残存、`trade_sharpe_raw` を別名列として追加
- `sharpe_calc_version` 追加（旧=`v1_bar_annualized`、新=`v2_trade_level`）
- **reader hard-fail**: 未知 `sharpe_calc_version` で例外

### canonical accessor

`GenomeArchive.get_sharpe(row)` を追加:
- v2 archive → `row["trade_sharpe_raw"]` を返す
- v1 archive → `None` を返すか例外（直接比較を禁止）
- 全 consumer（`run_ga.py` / `run_alpha_sieve.py` 含む）は `row["sharpe"]` 直接参照を廃止し accessor 経由に変更

### report 系スコープ

- Phase 1A: Alpha Factory 内部 consumer + `run_ga.py` / `run_alpha_sieve.py` を accessor 切替
- Phase 2: `backtest/report.py` / `ensemble_report.py` 等の外部公開名変更（別 TODO）
