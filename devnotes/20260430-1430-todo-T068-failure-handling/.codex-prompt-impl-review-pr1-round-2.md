## 1. [Warning H8] `evaluate_bc_safe` の `individual_index = int(...)` が try 外 (no-raise contract 境界逸脱)

修正: `int()` 変換を `try/except (TypeError, ValueError)` で囲み、 失敗時は `0` fallback.

```python
raw_index = evaluate_kwargs.get("individual_index", 0)
try:
    individual_index = int(raw_index)
except (TypeError, ValueError):
    individual_index = 0

try:
    result = evaluate_fn(**evaluate_kwargs)
except ...
```

該当箇所: `src/alpha_factory/failure_handling.py:541-548`

加えて test を 1 件追加 (`test_individual_index_non_int_falls_back_to_zero`):
非数 `individual_index="not-a-number"` を渡しても wrapper 外に例外が漏れず、 degraded `result.individual_index=0` で failure_record が返ることを検証.
