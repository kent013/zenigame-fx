```
| live_criteria | stress    | cross_pair | mission     |
|---------------|-----------|------------|-------------|
| False         | *         | *          | FAIL        |  ← live FAIL は最優先
| *             | *         | FAIL       | FAIL        |  ← cross_pair FAIL は最優先
| *             | FAIL      | *          | FAIL        |  ← stress FAIL は最優先
| True          | PASS      | PASS       | PASS        |  ← 全達成
| True          | PENDING   | PASS       | PENDING     |  ← stress 未実装で判定保留
```

実装:
```python
if not live_criteria_pass or cross_pair_pass == FAIL or stress_pass == FAIL:

    mission_pass = StagePassStatus.PASS
else:
    # live=True, cross_pair != FAIL, stress=PENDING のみ
    mission_pass = StagePassStatus.PENDING
```
