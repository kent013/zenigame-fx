## 概念設計 (revised)

# 概念設計: signal-eval-consistency-fix (無取引優位の選抜下位化)

## 背景・課題

### 観察事実 (Fact)

run-9 (run_20260425_002330) archive 横断:
- 無取引個体 (`trade_count=0`) が 90/120 (75%)、すべて `fitness_pen=0`
- 取引 30 個体は `fitness_pen=-8.91 ~ -93.10` (全て負 Sharpe)
- run-9 best は `g0_i1` (Stage A/B/C 全不通過、`trade_count=0`、`fitness=0`)

### 解釈 (Interpretation)

- Stage 全不通過の個体間で `selection_score` の `fitness_pen` 部分のみが差異
- `0.0 (無取引) > 負値 (取引)` で無取引が常勝

### 前提検証 (C4)

`scripts/alpha_factory/run_ga.py` `IndividualCacheEntry.selection_score`:
```python
return (int(self.stage_c_pass), int(self.stage_b_pass), int(self.stage_a_pass), float(self.fitness_pen))
```
辞書式比較。Stage 全不通過の個体間では `fitness_pen` のみが差異要因。

## 改善アイデア

### 単一施策: selection_score への feasibility tier 追加

```python
return (
    int(self.stage_c_pass),
    int(self.stage_b_pass),
    int(self.stage_a_pass),
    int(self.feasible_trade),   # 新規: trade_count >= 1
    float(self.fitness_pen),
)
```

- archive を変更しない (canonical `fitness_pen` / `total_pnl` は不変)
- `feasible_trade` は `_update_cache_from_archive` で archive row の `trade_count >= 1` から導出
- archive row 不在の個体は `feasible_trade=False`

## 期待効果

- `best_no_trade_rate` → 0
- `tc=0` 比率の有意低下 (5 RUN smoke check で descriptive 確認、有意性主張なし)
