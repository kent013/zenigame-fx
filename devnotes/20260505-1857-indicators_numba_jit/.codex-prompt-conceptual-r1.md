## 入力: 概念設計

# 概念設計: `_indicators.py` の Python loop 関数を Numba JIT 化

## 背景・課題

profile-optimize cycle 1/3 で `src/alpha_factory/primitives/_indicators.py` の以下 Python loop 関数が hot path:

| 関数 | profile tottime | 呼び出し回数 | per-call | 本番投影 (×295.9) |
|---|---|---|---|---|
| `_wilder_smooth` (line 214) | 1.000s | 28 | 36ms | 296s = 4.9 分 |
| `rolling_max` (line 116) | 0.465s | 14 | 33ms | 138s = 2.3 分 |
| `rolling_min` (line 137) | 0.463s | 14 | 33ms | 137s = 2.3 分 |
| `ema` line 191 | 推定 0.4s | - | - | ~120s = 2.0 分 |
| **合計** | **~2.3s** | | | **~700s = 11.7 分 (本番 100 分の 11.5%)** |

これらは再帰または monotonic deque で配列単位ベクトル化不可、 Numba JIT 化に最適。 zenigame パターン 2 実証 (parser._ema 76s→5s = 93%、 searchsorted 77s→5s = 93%) より conservative に 50-70% 削減見込み。

直近 RUN baseline 102 分に対して 5-8% 削減見込み。

## 改善アイデア

`_indicators.py` の 3 関数 (まず) に `@numba.njit(cache=True, fastmath=False)` 追加。 シグネチャ・semantics 不変、 呼び出し側コード変更不要。

### Numba 化 注意点

- **`deque` 不可**: `collections.deque` 非対応 → fixed-size circular buffer (numpy ndarray) で再実装
- **NaN 伝播**: `np.nanmean` は限定的サポート → 既存契約「呼び出し側で NaN 除外」 を維持して `np.mean` 使用
- **warmup logic**: `out[i<n-1] = NaN` (`np.full(NaN)`) は不変
- **数値同値性**: 既存実装と bit-identical (同じ演算順序、 同じ float64 中間型)

## 期待効果

- `_indicators.py` 3 関数の Numba 化で本番 RUN **5-8% 削減** (100 分 → 92-95 分)
- zenigame 実証 (93% 削減) より conservative に 50-70% 想定

## 実装方針

### 変更コンポーネント
1. `src/alpha_factory/primitives/_indicators.py`:
   - `import numba` 追加
   - `_wilder_smooth`, `rolling_max`, `rolling_min`, ema に `@numba.njit(cache=True, fastmath=False)`
   - `rolling_max` / `rolling_min` の `collections.deque` を `np.empty(n, dtype=np.int64)` + head/tail インデックス に置換
2. 既存テスト + 数値同値性テスト追加 (`np.allclose(atol=1e-12)`)

### 数値同値性保証
- `_wilder_smooth`: recurrence 演算順序・型・seed 計算同一 → bit-identical
- `rolling_max/min`: monotonic deque semantics 同じ (drop 条件 `<=` / `>=`、 等値は残す) → bit-identical
- 既存テスト 全 pass

## 制約・前提

- FX 絶対制約: `_indicators.py` は signal 値計算で取引執行に関与しない
- メモリ: 入出力 ndarray のみ、 増加なし
- 既存契約「呼び出し側で NaN 除外」 を維持 (`np.mean` 使用)
- `cache=True` で 2 回目以降即時、 初回 JIT 時間は benchmark 時除外

## スコープ外
- broker mock 系 (Decimal 故 Numba 不可)
- DSL composite kernel 拡張 (Codex で却下済)
- per-bar logging 削減 (cycle 3/3)
- session_block lookup table (別 cycle 候補)
