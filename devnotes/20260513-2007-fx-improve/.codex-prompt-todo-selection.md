### T099: PR5 Stage B gate pfr_only opt-in A/B

**背景**: archive 実測 Spearman ρ:
- median_oos_sharpe → trade_sharpe_stage_c: **ρ = -0.361** (逆予測！)
- positive_fold_ratio_effective → trade_sharpe_stage_c: **ρ = +0.345** (唯一の正予測)
→ 現 gate (median + pfr AND) は curve-fit 選好 (過去 Codex 議論 H_X'' PARTIAL CONFIRMED)

**目的**: `stage_b_gate_kind: Literal["legacy", "pfr_only"]` を追加。
- `legacy` (default): 現状 median+pfr AND
- `pfr_only` (opt-in): positive_fold_ratio_effective 単独 gate (>= 0.4)、median は observe-only

**期待効果**:
- curve-fit 個体 (median 偏重) の Stage B 通過率低下
- 持続性候補 (高 pfr) の通過率上昇
- Stage C 持続性回復

**Smoke 合格条件**:
- pfr_only mode で Stage B pass 数 ≥ legacy
- Stage C trade_sharpe_stage_c median ≥ legacy
- 悪化なら flag off

**変更**:
- `Phase5Config` 追加 (stage_b_gate_kind, pfr_threshold=0.4)
- `StageGateConfig` 4 段接続
- `evaluate_stage_b` 分岐 + observe-only median 出力
- CLI `--stage-b-gate-kind`
