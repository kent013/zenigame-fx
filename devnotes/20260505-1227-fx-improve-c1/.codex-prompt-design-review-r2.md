## Claude の対応 (全面採用)

### 採用版 (cycle 1 で実装する施策)

**C2 (絞り込み版)**: `collect_stage_a` で `total_pnl` を archive に伝搬 + 回帰テスト 1 本

- target_metric: total_pnl_min=50000 判定の正当性
- 仮説 H1: 「total_pnl=0 は Stage A payload→archive 伝搬欠落が原因」
- 反証: 修正後に sidecar `total_pnl_stage_a=50360.0` (g54_i35) と archive `total_pnl` が一致すれば verify、 不一致なら別経路の伝搬欠落 (cycle 2 で深掘り)
- 変更ファイル: `src/alpha_factory/archive.py` (collect_stage_a, line 409〜) + `tests/alpha_factory/test_archive.py` (回帰テスト 1 本)
- success_criterion:
  1. sidecar `total_pnl_stage_a` と archive `total_pnl` が同一個体で一致
  2. cycle 2 RUN で best 個体 `total_pnl > 0`
  3. 回帰テストで `collect_stage_a` 経路の `total_pnl` 伝搬を assert
- リスク: Stage A だけ修正で Stage B/C 集計と矛盾する可能性 → 実装時に collect_stage_b/c も確認 (ただし最小変更原則を維持)
